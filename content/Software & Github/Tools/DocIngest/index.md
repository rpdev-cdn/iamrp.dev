# DocIngest Documentation Suite

> [!abstract] Documentation Crawler & Corpus Viewer
> **DocIngest** is a self-hosted documentation crawler, parser, and semantic search engine. It scrapes canonical library documentation and structures it for immediate ingestion into Model Context Protocol (MCP) servers and AI reasoning loops.

---

### ◈ Available Interactive Tools

* **[[Software & Github/Tools/DocIngest/add|DocIngest URL Ingestion]]** (`/tools/docingest/add` or `/add`)  
  *Submit documentation URLs with wildcard path filters (`/docs/*`, `*/v1/*`) to crawl, convert to clean Markdown, and persist to the database.*

* **[[Software & Github/Tools/DocIngest/view|DocIngest Corpus Viewer]]** (`/tools/docingest/view` or `/view`)  
  *Search, inspect in-modal Markdown, copy context directly to the clipboard, or download full documentation bundles.*

* **[[Projects & Research/Projects/DocIngest_Engine|DocIngest Architecture Case Study]]**  
  *Detailed engineering deep dive on the underlying Firecrawl, Playwright, Redis, PostgreSQL, and RabbitMQ microservice backend.*
