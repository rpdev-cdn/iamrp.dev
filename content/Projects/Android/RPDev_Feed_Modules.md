## 📦 Verified Module Portfolio

1. **Privacy Weather** (`plugin_weather`): Open-Meteo geocoding & forecast with zero location tracking.
2. **Hardware & Battery Telemetry** (`plugin_sensors`): Direct kernel sysfs readings for temperature, wattage, and RAM.
3. **Calendar Agenda** (`plugin_calendar`): On-device 72-hour schedule scan.
4. **GitHub Pulse** (`plugin_github`): Repository pull request, issue, and commit tracker.
5. **Webpage Monitor & Keyword Scraper** (`plugin_web_scraper`): Jsoup HTML scraper with MD5 diff change alerts.
6. **Custom REST / JSON Endpoint** (`plugin_dynamic_rest`): Polling engine with dot-notation path extraction.
7. **Home Assistant State Monitor** (`module_home_assistant`): Smart home presence, lighting, and climate entities.
8. **Docker Fleet Health** (`module_docker_telemetry`): Container statuses, CPU/memory, and restart counts.
9. **Uptime Kuma Status Monitor** (`module_uptime_kuma`): Service ping latencies and incident status.
