## 🧭 What You'll Find in the Wiki

The **[RPDev Master Wiki](https://wiki.iamrp.dev)** is built with a dual-lens approach: designed for everyday end users who want clear, step-by-step guidance, as well as developers needing low-level architectural specifications.

| Knowledge Hub | Address | Target Audience |
|---|---|---|
| **Quick Start & Installation** | [wiki.iamrp.dev/getting-started/](https://wiki.iamrp.dev/getting-started/) | Step-by-step guides to install and configure RPDev Launcher and Feed on Android 16. |
| **RPDev Launcher User Manual** | [wiki.iamrp.dev/launcher/](https://wiki.iamrp.dev/launcher/) | Mastering nested folders, cycle detection, gestures, and drawer folder icons. |
| **RPDev Feed User Manual** | [wiki.iamrp.dev/feed/](https://wiki.iamrp.dev/feed/) | Setting up RSS feeds, offline caching, layout customization, and zero telemetry. |
| **Modules Hub (9 Subsections)** | [wiki.iamrp.dev/modules/](https://wiki.iamrp.dev/modules/) | Complete guides for Weather, Sensors, Calendar, GitHub, Web Scraper, Home Assistant, Docker, and Uptime Kuma. |
| **Developer & AIDL Specs** | [wiki.iamrp.dev/developers/](https://wiki.iamrp.dev/developers/) | Building from source, `ILauncherOverlay` AIDL protocols, and custom card development. |
| **Projects Knowledge Base** | [wiki.iamrp.dev/projects/](https://wiki.iamrp.dev/projects/) | Comprehensive technical documentation for all bare-metal, network, and security systems. |
